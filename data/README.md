# Telco Customer Churn Dataset

This folder contains the dataset used by the Customer Churn Prediction & Retention Intelligence System.

## Dataset Source

The dataset originates from IBM's Telco Customer Churn repository:

https://github.com/IBM/telco-customer-churn-on-icp4d

## Purpose

The dataset is used for educational and portfolio purposes, including:

* Exploratory data analysis
* Data preprocessing
* Machine learning model training and evaluation
* Customer churn prediction
