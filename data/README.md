# Telco Customer Churn Dataset

This folder contains instructions for obtaining the dataset used by the Customer Churn Prediction & Retention Intelligence System.

## Dataset Source

The dataset originates from IBM's Telco Customer Churn repository:

https://github.com/IBM/telco-customer-churn-on-icp4d

Please consult the original repository for the dataset and verify the applicable terms of use before downloading or redistributing it.

## How to Set Up the Dataset

1. Visit the dataset source linked above.
2. Locate and obtain the Telco Customer Churn CSV file, subject to its applicable terms.
3. Place the CSV file in this folder.
4. Ensure the filename is exactly:

   `Telco-Customer-Churn.csv`

The expected project path is:

`data/Telco-Customer-Churn.csv`

**Note:** The dataset is not included in this GitHub repository. You must obtain it separately.

## Purpose

The dataset is used for educational and portfolio purposes, including:

* Exploratory Data Analysis (EDA)
* Data preprocessing and cleaning
* Machine learning model training and evaluation
* Customer churn prediction
